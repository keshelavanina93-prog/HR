# 02 — გამოცდილება, IA, დიზაინის სისტემა და სრული ქართული ტექსტები

## 1. ორი ძირითადი გამოცდილება, ერთი ბრენდი

**PUBLIC / editorial marketplace** — ამოცანა: აღმოჩენა, სანდოობა, კომპანიის/ტრენერის/კურსის რეალური ისტორია, მაღალი ხარისხის კონტენტი. მაღალი ხარისხის ფოტოგრაფია, ტიპოგრაფია, ინდივიდუალური გვერდები.

**WORKSPACE / operating product** — ამოცანა: გააკეთე საქმე. კომპაქტური ინფორმაცია, სამუშაო რიგი, სტატუსები, შედარებები, კონტექსტური მოქმედებები, audit trail. არ შეიძლება იყოს მხოლოდ ღრმა ტექსტებით გაფორმებული landing page. ყოველი ზედა სექცია უნდა პასუხობდეს კითხვას: **რა მოქმედება შეუძლია მომხმარებელს აქ, ახლავე?**

**მობილურზე:** საჯარო გვერდები სრულფასოვანი. სამუშაო გარემოში პირადი საქმეებისა და მდგომარეობის სწრაფი მართვა; ფართო შედარების მატრიცა ტელეფონზე გადაიქცეს ვერტიკალურ შეთავაზებებად; არ დაიკარგოს ინფორმაცია.

## 3. კომპანიასთან კომუნიკაციის ტექსტები — საბოლოო სარედაქციო მიმართულება

### Business hero — მთავარი ვარიანტი

**სათაური:** „ადამიანებთან დაკავშირებული საქმე — დასრულებამდე.“

**ქვესათაური:** „ვაკანსიიდან მიღებულ კანდიდატამდე. სასწავლო საჭიროებიდან შერჩეულ მომწოდებლამდე. ერთი სისტემა, სადაც ხედავ, რა ხდება, ვინ მოქმედებს და რა არის შემდეგი ნაბიჯი.“

## 4. ვაკანსიის გვერდის სრული საინფორმაციო იერარქია

1. Employer identity: სახელი, დადასტურების სტატუსი, სექტორი, მდებარეობა, ოფიციალური ვებსაიტი.
2. Position header: მხოლოდ პოზიციის სახელი, დეპარტამენტი, სამუშაო ფორმატი.
3. Salary: `3,500–5,000 ₾ / თვე / დარიცხული`, სრული სამუშაო გრაფიკი.
4. What success looks like: რას აკეთებს ადამიანი პირველ 90 დღეში / რა შედეგი სჭირდება როლს.
5. Responsibilities: 4–8 კონკრეტული სამუშაო პასუხისმგებლობა.
6. Requirements: აუცილებელი და სასურველი გამოცდილება მკაფიოდ გაყოფილი.
7. Working environment: რეალური გუნდის/მენეჯერის/სამუშაო გარემოს ინფორმაცია მხოლოდ ნებართვით და ფაქტობრივი წყაროთი.
8. Hiring process: ეტაპები, სავარაუდო დრო, უკუკავშირის დაპირება, ვადა.
9. Apply: საიტის შიგნით ან დამტკიცებული გარე ATS-ით; მობილურზე მარტივი პროცესი.
10. Change log: ბოლო განახლების დრო, გაუქმებული/დახურული სტატუსი.

## 5. 2026 დიზაინის მოთხოვნები (დეკორაციის გარეშე)

- ფონები: porcelain, chalk, graphite. **არავითარი მწვანე** ბრენდის ტოკენებში.
- შრიფტი: ქართული ნორმალური ვებშრიფტი; editorial serif მხოლოდ სათაურებს. UI labels — მკაფიო sans.
- Motion: ინფორმაციული გადასვლები 150–300ms, არა დეკორატიული მუდმივი პარალაქსი; prefers-reduced-motion.
- Content: რეალური ვიზუალური იდენტობა; ორგანიზაციების ფოტოები მხოლოდ უფლებებით; fallback ტექსტური, არა გამოგონილი ადამიანები.
- Forms: autosave დრაფტები სერვერზე (სამიზნე), მკაფიო errors, progress, preview, accessible labels.
- Data display: არ გამოიყენო ხელოვნური „+240%“ ან ყალბი testimonials.
- Accessibility: keyboard, screen reader labels, form errors, contrast AA, focus visible, touch targets ≥44px.
- Responsive: 320px width without horizontal overflow; desktop 1440; zoom 200%.
- Design QA: screenshot regression ყველა მთავარ გვერდზე + accessibility audit.
